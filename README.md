# 🎮 Simon Says Game (JavaScript)

An interactive **Simon Says memory game** built using **HTML, CSS, and JavaScript**, where players must repeat an increasing sequence of colors correctly.

🔗 **Live Demo:** https://simon-says-two-tau.vercel.app

---

## 🚀 Features

* 🎯 Dynamic sequence generation
* 🧠 Memory-based gameplay
* 📈 Increasing difficulty with each level
* 🎨 Visual feedback for user actions
* ❌ Game over detection on wrong input
* 🔄 Restart functionality

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (DOM Manipulation & Game Logic)

---

## 🎮 How to Play

1. Press any key (or start button) to begin
2. Watch the sequence of colors carefully
3. Repeat the sequence by clicking the colors
4. Each level adds a new step to the sequence
5. Game ends if you click the wrong color
